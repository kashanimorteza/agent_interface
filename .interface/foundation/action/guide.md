# Action

This directory holds the kinds of work an Agent can be asked to do. Each action is one Markdown file that defines for the model what that kind of work means — what counts as programming work, analysis work, review work, planning work — so that a request can be classified and handled consistently. Actions are Human-owned and live under Foundation because they are shared definitions, not a Module.

<br>

## Contents

```text
action/
├── guide.md
├── develop.md
├── analyze.md
├── review.md
└── plan.md
```

- [Develop](develop.md) — programming work.
- [Analyze](analyze.md) — analysis work.
- [Review](review.md) — review work.
- [Plan](plan.md) — planning work.
