# Personality

This directory holds the personalities an Agent can take on. Each personality is one Markdown file describing one way of working — who the Agent is while it does a kind of work: its stance, priorities, and the judgment it applies. Personalities are Human-owned and live under Foundation because they are shared definitions, not a Module.

<br>

## Contents

```text
personality/
├── guide.md
├── developer.md
├── planner.md
├── analyst.md
├── reviewer.md
└── architect.md
```

- [Developer](developer.md) — writes and changes code.
- [Planner](planner.md) — turns a goal into bounded, ordered work.
- [Analyst](analyst.md) — examines and explains without changing.
- [Reviewer](reviewer.md) — judges whether done work satisfies what was asked.
- [Architect](architect.md) — creates and corrects structure.
