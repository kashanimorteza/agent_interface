# Model

## Overview

Model is the Trading Assistant's reusable data library. It defines every Entity of the application once, in a technology-independent Declaration, and publishes each Entity as a strictly validated type that converts losslessly to and from JSON text and carries a table-ready storage form. Model never runs storage, holds no data, and performs no application behaviour.

```python
from model.interface import Currency

usd = Currency(user_id=1, code="USD", symbol="$", country="United States")
print(usd.to_json())
# {"id":null,"user_id":1,"code":"USD","symbol":"$","country":"United States","decimal_digits":2,"is_active":true,"description":null}
```

## Interface

The Interface is the only publishing entrypoint (`model.interface`, Interface contract version `2.1`). It publishes two forms and nothing else:

- **Entity Exports** — every Entity by its own name, for a consumer that works with one specific Entity.
- **Entity Collection** — `entities`, an immutable tuple holding every Entity once, in Target order, for a consumer that works with all Entities without knowing their names.

Import one Entity directly by name:

```python
from model.interface import Account

print(Account.declaration.name)
# Account
```

Enumerate every Entity through the Entity Collection:

```python
from model.interface import entities

for entity in entities:
    print(entity.declaration.name, len(entity.declaration.fields))
```

Loading the Interface creates no Entity instance, data, connection, file, or process.

### Entities

Every Entity has the Identity `id` (an integer generated by storage, immutable) and the Activity Field `is_active` (a mutable boolean). A Field with `—` as its default and `no` under Nullable, and no Value Generation, is required.

## Declaration

Each Entity exposes its public Declaration as the read-only class attribute `declaration`. A Declaration is an immutable record; its collections are tuples.

```python
from model.interface import Account

declaration = Account.declaration
print(declaration.name, "-", declaration.description[:40])
for field in declaration.fields:
    print(field.name, field.type, field.nullable, field.default, field.sensitivity)
print("Primary Key:", declaration.primary_key)
for relation in declaration.relations:
    print(
        "Relation:",
        relation.local_field,
        "->",
        relation.target_entity,
        relation.target_field,
    )
for constraint in declaration.unique_constraints:
    print("Unique:", constraint.fields)
print("Indexes:", declaration.indexes)
```

| Entity Declaration member | Meaning |
|---|---|
| `name` | The logical Entity name, exactly as the Target spells it. |
| `description` | The Entity's meaning. |
| `fields` | The ordered Field Declarations. |
| `primary_key` | The Field named by the Primary Key (always `id`). |
| `relations` | Each Relation's `local_field`, `target_entity` (logical name), and `target_field`. |
| `unique_constraints` | Each Uniqueness Constraint's ordered `fields`. |
| `indexes` | Each Index's ordered `fields`. |

| Field Declaration member | Meaning |
|---|---|
| `name` | The Field name. |
| `type` | One of `string`, `integer`, `float`, `decimal`, `boolean`, `datetime`, `date`, `time`, `uuid`. |
| `nullable` | Whether null is a valid value. |
| `description` | The Field's meaning, or `None`. |
| `default` | The Default Value, or `NO_DEFAULT` when the Field has none (distinct from an explicit `None` default). |
| `sensitivity` | `password`, `sensitive`, or `None`. A marker records meaning only; Model never protects or transforms the value. |
| `immutable` | Whether the value can change after construction. |
| `constraints` | Value constraints; `size` is a maximum string length. |
| `value_generation` | `auto_increment`, `generated_identifier`, or `None`. |

`NO_DEFAULT` and the closed sets `FieldType`, `ValueGeneration`, and `Sensitivity` come from `model.core.declaration`.

## Foundation

Every Entity extends Foundation, which converts it to and from its JSON Object: JSON text with one root object whose keys are exactly the Entity's Fields, in Declaration order.

`to_json()` returns the JSON text of an Entity:

```python
from decimal import Decimal

from model.interface import Account

account = Account(
    name="Acc-1",
    group_id=1,
    broker_id=1,
    instance_id=1,
    base_currency_id=1,
    username="example",
    password="example-password",
    leverage=100,
    balance=Decimal("1250.75"),
    account_type="CFD",
)
print(account.to_json())
```

`from_json(text)` builds an Entity from JSON text with the same rules as direct construction:

```python
from model.interface import Broker

broker = Broker.from_json('{"name": "FxPro", "user_id": 1}')
print(broker.name, broker.is_active)
# FxPro True
```

A complete round trip returns an equal Entity, with decimals and datetimes kept exactly:

```python
from datetime import datetime, timezone
from decimal import Decimal

from model.interface import Position

position = Position(
    user_id=1,
    name="P-1",
    trading_platform_id=1,
    broker_id=1,
    account_id=1,
    trailing_group_id=1,
    partial_group_id=1,
    action_group_id=1,
    action_id=1,
    date=datetime(2026, 5, 1, 12, 30, tzinfo=timezone.utc),
    volume=Decimal("0.10"),
    order_type="buy",
    base_tp=Decimal("1.08750"),
    base_sl=Decimal("1.08250"),
    real_tp=Decimal("1.08750"),
    real_sl=Decimal("1.08250"),
)
text = position.to_json()
assert Position.from_json(text) == position
print(text)
```

JSON forms: `decimal`, `datetime`, `date`, `time`, and `uuid` are strings (a datetime always carries its offset); `float` and `integer` are numbers; `boolean` is `true` or `false`; an absent value is `null`. A not-yet-generated `id` is `null`.

3. For a Component of this project that consumes Model, add it as a local path dependency from that Component's directory: `uv add ../model`.

## Use

Construct an Entity with keyword arguments. Every value is validated strictly before anything is set: an unknown Field, a value of the wrong Type, or a missing required Field is refused, with no implicit coercion.

```python
from pydantic import ValidationError

from model.interface import TradingPlatform

platform = TradingPlatform(name="Binance", code="binance")

try:
    TradingPlatform(name="MetaTrader 5")
except ValidationError as error:
    print(error.errors()[0]["type"], error.errors()[0]["loc"])
# missing ('code',)
```

Assignment validates the whole Entity with the new value; a refused assignment keeps the previous value. `id` is generated by storage, so it cannot be supplied or assigned:

```python
from pydantic import ValidationError

from model.interface import Asset

asset = Asset(
    broker_id=1, symbol="EUR/USD", category="Currency", point_size=0.0001, digits=5
)
asset.is_active = False

try:
    asset.digits = "5"
except ValidationError:
    print("refused; digits is still", asset.digits)

try:
    Asset(id=7, broker_id=1, symbol="XAU/USD", category="Commodity")
except ValidationError as error:
    print(error.errors()[0]["type"])
# generated_value
```

Work with all Entities without naming them through the Entity Collection:

```python
from model.core.declaration import NO_DEFAULT
from model.interface import entities

required = {
    entity.declaration.name: [
        field.name
        for field in entity.declaration.fields
        if not field.nullable
        and field.value_generation is None
        and field.default is NO_DEFAULT
    ]
    for entity in entities
}
print(required["Currency"])
# ['user_id', 'code']
```

Each Entity also carries its table-ready form. A storage consumer reaches the shared table metadata through the Entities themselves, for example `entities[0].metadata`, which holds exactly the Entity tables. Model itself never runs storage.

## Verify

Run this check from the Model Component directory with `uv run python` in a fresh interpreter to confirm that the Interface matches its contract, that loading it has no side effect, and that Entities construct and round-trip:

```python
import gc
import importlib
import os
import sys
import threading
from decimal import Decimal

files_before = set(os.listdir("."))
threads_before = threading.active_count()
objects_before = len(gc.get_objects())

interface = importlib.import_module("model.interface")
entities = interface.entities

# Side-effect freedom: loading created no file, thread, or Entity instance.
assert set(os.listdir(".")) == files_before
assert threading.active_count() == threads_before
assert not [
    item for item in gc.get_objects()[objects_before:] if isinstance(item, entities)
]

# The Entity Collection holds every Entity once, in Target order.
target_order = [
    "User",
    "TradingPlatform",
    "Instance",
    "Currency",
    "Broker",
    "Asset",
    "AccountGroup",
    "Account",
    "TrailingGroup",
    "TrailingRule",
    "PartialGroup",
    "PartialRule",
    "ActionGroup",
    "Action",
    "Position",
]
assert isinstance(entities, tuple)
assert [entity.__name__ for entity in entities] == target_order

# Exact Entity Export membership, corresponding to the Collection.
published = sorted(name for name in vars(interface) if not name.startswith("_"))
assert published == sorted([*target_order, "entities"]), published

for entity in entities:
    # Each export is the actual Entity and exposes its actual Declaration.
    assert getattr(interface, entity.__name__) is entity
    assert entity is getattr(sys.modules[entity.__module__], entity.__name__)
    declaration = entity.declaration
    assert [field.name for field in declaration.fields] == list(entity.model_fields)
    assert declaration.primary_key == "id"

# The Declaration and the Collection are immutable.
try:
    entities[0].declaration = None
    raise AssertionError("declaration is writable")
except AttributeError:
    pass
try:
    entities[0] = None  # type: ignore[index]
    raise AssertionError("the Entity Collection is writable")
except TypeError:
    pass

# Representative construction, Declaration access, and a lossless JSON text round trip.
Account = interface.Account
account = Account(
    name="Acc-1",
    group_id=1,
    broker_id=1,
    instance_id=1,
    base_currency_id=1,
    username="example",
    password="example-password",
    leverage=100,
    balance=Decimal("1250.75"),
    account_type="CFD",
)
assert Account.declaration.name == "Account"
assert Account.from_json(account.to_json()) == account
print("Model verified:", len(entities), "Entities")
```

## Troubleshooting

- **`ValidationError` with type `generated_value`** — a value was supplied or assigned for `id`. Leave `id` out; storage assigns it.
- **`ValidationError` with type `frozen_field`** — an immutable Field was assigned after construction.
- **`ValidationError` with type `extra_forbidden`, `missing`, or a `*_type` error** — the input has an undeclared Field, lacks a required Field, or has a value of the wrong Type. Values are never coerced: pass `Decimal` objects for decimal Fields, timezone-aware datetimes for datetime Fields, and floats for float Fields.
- **`ValidationError` with type `text_form` or `json_invalid` from `from_json`** — the JSON text is malformed, repeats a key, uses `NaN` or `Infinity`, has a root that is not an object, or gives a decimal, datetime, date, time, or uuid value in a form other than its text form.
- **`[hidden sensitive value]` in an error** — the input belonged to a Field carrying a Sensitivity Marker; Model never repeats such a value in diagnostics.
- **`TypeError: ... does not match its Declaration` on import** — an Entity type's name, table name, Fields, Field order, or Field realization differs from its Declaration.
- **`TypeError: Entities support only validated construction, ...`** — copying, unvalidated construction, and reconstruction other than `from_json` are not part of the Entity contract; build a new Entity or use `to_json` and `from_json`.
- **`AttributeError: Field ... cannot be removed`** — Fields cannot be deleted from an Entity.
- **`DeclarationError`** — a Declaration is structurally invalid, for example a duplicate Field, a default that does not match its Type, or a Relation or constraint naming an unknown Field.
