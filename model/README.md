# Model

## Overview

Model publishes the Trading Assistant's data-model Entities and their complete public meaning as a reusable Python library. Every Entity states its Fields and Entity Metadata in a public Declaration, and every Entity converts to and from JSON text without loss. Model defines no tables, queries, endpoints or application behaviour.

```python
from model.interface import Broker

broker = Broker(user_id=1, name="FxPro")
print(broker.id)         # None: the identity is pending until its owner assigns it
print(broker.is_active)  # True: the Target default
print(broker.to_json())  # {"id":null,"name":"FxPro","user_id":1,"is_active":true,"description":null}
```

## Interface

`model.interface` is the only entry point. It publishes every Entity by its own name and one ordered, immutable collection of all of them, `entities`, in the order below. Nothing else publishes Entities: there is no wildcard export, registry or lookup.

Import one Entity directly:

```python
from model.interface import Currency

currency = Currency(user_id=1, code="USD")
```

Enumerate every Entity without knowing their names:

```python
from model.interface import entities

print([entity.__name__ for entity in entities])
# ['User', 'TradingPlatform', 'Instance', 'Currency', 'Broker', 'Asset', 'AccountGroup', 'Account', 'TrailingGroup', 'TrailingRule', 'PartialGroup', 'PartialRule', 'ActionGroup', 'Action', 'Position']
```

Loading the Interface creates no Entity, data, connection, file or process.

Every Entity has an `id` (non-nullable, immutable, generated by its owner) and a Boolean `is_active` (non-nullable, default `true`). A nullable Field without a Default Value may be omitted, and its value is then null.

## Declaration

Every Entity exposes its own Declaration as the class attribute `declaration`. A Declaration is a frozen record holding `name`, `description`, `fields`, `primary_key`, `relations`, `unique_constraints` and `indexes`. Each entry of `fields` records `name`, `description`, `type`, `nullable`, `has_default`, `default`, `sensitivity`, `immutable`, `constraints` and `value_generation`. A Relation records `local_field`, `target_entity` and `target_field`. `has_default` tells an absent Default Value apart from an explicit null.

```python
from model.interface import Instance

declaration = Instance.declaration
print(declaration.name)                                  # Instance
print([field.name for field in declaration.fields][:3])  # ['id', 'user_id', 'trading_platform_id']
print(declaration.primary_key)                           # id
print(declaration.relations)
# (Relation(local_field='user_id', target_entity='User', target_field='id'), Relation(local_field='trading_platform_id', target_entity='Trading Platform', target_field='id'))
print(declaration.unique_constraints)                    # (('user_id', 'name'),)
print(declaration.indexes)                               # ()
print(declaration.fields[0].value_generation)            # auto_increment
```

## Foundation

Every Entity converts to JSON text with `to_json()` and is rebuilt from it with `from_json()`. The text has one object at its root whose keys are the Field names in Declaration order. Decimals are strings, datetimes are ISO 8601 strings with their offset, and null, `false`, zero and the empty string stay distinct. A pending identity is written as `null`.

Convert an Entity to JSON text:

```python
from decimal import Decimal

from model.interface import TrailingRule

rule = TrailingRule(name="Half", trailing_group_id=1, trigger_percentage=Decimal("50.50"))
print(rule.to_json())
# {"id":null,"name":"Half","trailing_group_id":1,"trigger_percentage":"50.50","take_profit_adjustment":null,"stop_loss_adjustment":null,"is_active":true,"description":null}
```

Rebuild an Entity from JSON text:

```python
from model.interface import TrailingRule

rule = TrailingRule.from_json(
    '{"name":"Half","trailing_group_id":1,"trigger_percentage":"50.50"}'
)
print(rule.trigger_percentage)  # 50.50
```

One complete round trip, Entity to JSON text and back:

```python
from decimal import Decimal

from model.interface import TrailingRule

rule = TrailingRule(name="Half", trailing_group_id=1, trigger_percentage=Decimal("50.50"))
again = TrailingRule.from_json(rule.to_json())
print(again == rule)             # True
print(again.trigger_percentage)  # 50.50
```

`from_json` rejects malformed text, a root that is not an object, an undeclared key and a wrongly typed value.

## Use

Use Model only through `model.interface`.

```python
from model.interface import Currency, entities

usd = Currency(user_id=1, code="USD", symbol="$")
print(usd.decimal_digits)  # 2: the Target default applies to an omitted Field
usd.is_active = False      # a mutable Field accepts a valid change
usd.id = 7                 # the owner of the identity assigns it once
print(usd.id)              # 7

for entity in entities:
    print(entity.declaration.name)
```

Construction and assignment enforce every Field contract without converting values:

```python
from pydantic import ValidationError

from model.interface import Currency

try:
    Currency(user_id=1, code="USDX")
except ValidationError as error:
    print(error.errors()[0]["loc"])  # ('code',)
```

An invalid assignment is rejected and the previous value stays. An immutable Field, such as `id` once assigned, cannot change. A generated Field, such as `id`, cannot be supplied on construction.

## Troubleshooting

| Symptom | Resolution |
| --- | --- |
| `ModuleNotFoundError: No module named 'model'` | Run from this directory with `uv run`, or activate the environment created by `uv sync`. |
| `requires-python` or a syntax error on import | Use Python 3.14 or newer. |
| `Extra inputs are not permitted` | The Entity does not declare that Field; use a name from its table above. |
| `Field is generated by its owner and cannot be supplied` | Omit `id` on construction; its owner assigns it afterwards. |
| `Input should be an instance of Decimal` | Supply a `decimal.Decimal`, not a number or string. |
| `Input should have timezone info` | Supply a timezone-aware `datetime`. |
| `Field is immutable once assigned` | The Field cannot change after it has a value. |
| `Field never accepts a null value` | A generated Field is assigned a value, never null. |
| A `ValidationError` from `from_json` | The text is not a valid JSON object for that Entity; compare it with the output of `to_json()`. |
| `ValueError` or `TypeError` naming an Entity, Field or Relation while importing | Model's own definitions disagree; report the named item to the Model owner. |
